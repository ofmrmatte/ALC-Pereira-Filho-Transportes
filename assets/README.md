# Assets

Diretório reservado para os arquivos oficiais do site.

Organização planejada:

```text
assets/
├── brand/      # logotipo, símbolos e arquivos institucionais
├── images/     # fotos otimizadas para web
└── videos/     # vídeos oficiais da frota e operação
```

Não versionar arquivos brutos de alta resolução sem necessidade. Manter aqui apenas versões preparadas para uso web.
